# 整本朗读与阅读位置

在书籍库导入《红楼梦》等完整电子书，展开书籍后使用「朗读」。直播页只提供资料库入口，不单独上传或选择文件。支持20MB以内的TXT、Markdown、无加密EPUB，正文最多一千万字。TXT自动识别UTF-8、UTF-16 BOM和GB18030；EPUB遵循spine章节顺序提取正文，不执行脚本。PDF目前只支持预览，扫描图像不作文字识别。

也可以直接聊天：“读《红楼梦》”“请读红楼梦”“继续读书”“暂停阅读”。书名必须对应资料库中的唯一书籍；未找到或有重名时会提示选择，不编造正文。

资料库朗读按钮下的「持续读到全书结束」默认开启，随时可暂停；关闭则播完当前一段、保存进度后暂停。聊天可说“读《红楼梦》，只读一段”或“读《红楼梦》，读完”切换。此偏好保存在当前浏览器，所有角色共用，书签仍按角色与书籍分别保存。

选择角色后点击「开始阅读」或「继续阅读」，会开启本机角色语音。朗读直接使用导入的原文，不依赖文本模型续写；每次只将一个有限片段交给该角色配置的语音服务，未配置语音模型时使用浏览器系统语音。语音模型可能按调用收费。

进度按角色、书籍独立保存，包括已完成的字符位置和章节。同一本书切走再切回来会恢复原位置；全文和书签保存在本机后端SQLite中，刷新页面或重启服务不会清空。替换同一资源的实际正文时重置该书所有角色的进度；重复导入相同正文保留进度。删除书籍同时删除后端全文和书签。浏览器原文件仍按资源库原方式保存在IndexedDB中。

每段优先在段落、句末或章节边界停下。只有自然播放结束的回执才能推进书签；生成语音、开始播放、暂停、取消和播放失败均不推进。因此半段中断后会从这段开头重读，不会跳过尚未播放的正文。关闭页面或断电时未送达的回执也可能造成重读一段。可暂停、继续、选择章节或从头重读；「已读完」以服务确认到达正文结尾为准。

同时打开多个页面时，服务只让一个页面领取当前片段，领取状态会续期；其他页面等待。旧页面的迟到完成/取消回执不能推进或暂停后来领取的片段。暂时保存失败时先重试原回执，成功后才读取下一段。

直播读书期间自动杂谈等待，真实弹幕回复仍可进入语音队列；朗读结束后自然穿插，随后接下一段。读完全书后退出阅读状态，自动主持按原条件继续。停止直播或本地直播到时会暂停读书并保留位置。阅读需要保持主页面运行；功能不会自动启动OBS或平台推流。

默认共享资源可用于公开直播；指定角色私有的书籍只供获授权角色在非直播状态阅读。公开直播开始后，不允许领取私有书籍正文。模型讨论只得到当前进度附近有限原文，不把整本小说塞进提示词，也不等同于对全书内容建立了长期语义记忆。

接口位于`/api/library/books/{book_id}/file`和`/api/library/reading/{agent_id}`，使用`next`领取原文、`ack`确认完成、`cancel`保留位置暂停。`ack`可重试，不接受客户端自行上报任意已读位置；跳章是明确的选择操作。

读书时，对话输入区上方和直播控制区会显示书名与“显示原文 / 隐藏原文”按钮。默认隐藏，展开后展示实际阅读片段，随阅读更新；此开关只控制显示，不暂停朗读、不改变书签。
