# 全天直播模式

入口：角色设置 → 直播设置 → 主持方式选择「按作息主持」→ 调整作息。默认关闭；配置后保存，再在直播面板启动绑定角色的直播互动。需要可用的角色文本模型、本地服务持续运行和已接通的弹幕来源。浏览器打开并开启语音时才有本地角色语音播放；服务不会自动打开浏览器、启动OBS或向平台推流。

## 作息与内容

默认按 Asia/Shanghai 时区安排：00:00休息、08:00早间见面、09:00知识与兴趣、12:00午间休息、14:00午后故事、16:00兴趣闲聊、18:00傍晚休息、19:00晚间主题、21:00虚构梦境、22:00夜间休息。

可以编辑时区、每段名称、活动和内容习惯；最多16段，必须从00:00开始，开始时间递增且不重复。每段持续到下一段，末段到午夜。当前作息按真实时钟和指定时区确定，支持跨午夜，不调用模型判断时间。系统休眠期间不补播错过的节目。

角色结合个人性格、偏好、习惯、节目主题与公开资料主持；自动主持统一进行公开杂谈，旧回忆或梦境时段不会自动公开内心故事。每段主题用于公开资料检索，继续参考本场实际讨论。作息是节目安排，不声称真的吃饭、外出或睡觉。可申请播放共享目录中的音乐、连续朗读已导入的共享书籍全文并保留进度，见[整本朗读](BOOK_READING.md)；动作仍由能力与目录检查约束，不代表真实生活活动。

## 运行与控制

- 全天模式接管普通冷场主持的间隔和连续次数限制，即使普通冷场开关关闭，也可按作息继续主持。默认主动话题间隔180秒，可配置60–1800秒。
- 每次开启互动后，首次调度开始计时，最多24小时；到期停止生成，不自动续订。暂停后重新启动或更换绑定角色开启新一轮。
- 默认一轮最多200次主动尝试，可设1–1000次；失败、重复、审核拦截、被观众打断的已启动尝试都计入。观众发言不会重置总量。总量是次数限制，不是token或费用预算；观众触发的回复不包含在这个上限内。
- 休息时暂停主动生成和观众回复，但继续接收弹幕；不在休息结束后集中回复积压旧消息。24小时到期后同样不再回复。
- 收到新观众消息取消主动生成，优先排队回应；休息或过期检查同时覆盖生成前和投递前，跨时段的旧主动话题丢弃。新作息或节目配置会使生成中的旧主动结果失效。
- 内容检查、公开资料隔离和停止按钮继续有效。进入休息/到期事件时，前端停止当前频道直播语音。已播放或外部桥接已取走的内容不能撤回。
- 直播面板显示当前时段、下一开始时间和主动尝试用量；“收尾回顾”环节会继续阻止主动生成，即使全天模式已开启。

配置持久保存，运行时计时、用量和本场故事在内存中，服务重启后清空且直播互动不会自行恢复。当前没有崩溃自动续播、跨进程预算、持久化节目流水或真实平台24小时稳定性实测。自动测试使用模拟时钟与替身模型验证边界，不等于已持续直播24小时；语义内容审核仍待独立接入。

## 时间感与表情回应

直播回应现在得到服务计算的当前本地时间、本场持续秒数、距离最近一次播出及观众发言的间隔。持续时间采用单调时钟，时区采用角色作息时区；只在生成回应时读取，不额外调用模型。每个直播间独立、请求间隔离，重启互动或更换绑定重新计时。排练只有当前时间，不虚构开播时长。提示词要求按间隔承接话题，必要时自然提到时间，不能据此声称观众持续陪伴、身体疲劳或离线生活。

模型结合聊天语境、角色性格选择六类受限表情；沿用角色各自的表情丰富度、动作活跃度和气质调整强度。漏返回表情对象时使用保守的本地内容匹配，而非一律变成自然表情；自主故事的备用表情按实际故事文本判断，不按检索关键词判断。备用匹配不能可靠理解全部反讽/否定，语境主要由文本模型判断；模型能否显示具体表情仍受当前3D/Live2D模型能力限制。前端只驱动当前选中角色，不同时渲染所有直播角色。未增加独立情绪识别模型或真实主观意识。


## 本地无人直播测试

主界面右上角「直播模式」打开直播页，点击「开启直播模式」即可，无需平台账号、弹幕桥接或手动发消息。可选择10分钟/1小时/4小时/24小时及5秒/10秒/20秒/45秒/2分钟/5分钟的参考等待时间；默认1小时、45秒。首轮约2秒开始。模型可在5–600秒内调整下一段的等待；间隔不决定换题或语速。

开启语音后，主页面在准备和播放期间向后端报告状态，自动主持等播放结束再计算停顿；新直播回复依次播放，表情随该段语音开始。没有播放回执时从生成完成后起算。回执90秒未续期会失效，关掉页面不会永久堵住主持；休眠或网络中断时无法保证音画同步。弹幕仍可及时进入生成队列，优先于新的自动话题。

测试复用角色性格、公开知识、直播安全限制与最近10轮公开上下文；不读取私人聊天、旧模型直播归档或灵感缓存。每场另有简短的公开话题进度，帮助插话后接回未完内容，不作为口播。测试期间临时开启自主主持、忽略原作息休息段与结束节目状态，不修改角色保存的节目设置。普通冷场模式的最多3次上限不用于此测试；测试受设定时长与生成次数预算约束，不会无限调用。页面显示发言次数、剩余时长、语音/生成/等待状态和停止原因。

格式混入、明显重复句式和部分虚构亲身经历会触发最多一次模型修正，仍不合格则不播出；修正可能额外产生一次模型调用。规则不能完整识别语义重复或不实信息，话题判断与自然程度仍受配置的文本模型影响，不等于真人水平。

需要已配置可用的角色或全局文本模型；启动前检测配置，模型消失或连续生成异常3次会停止。点击停止会取消正在生成的内容、终止语音并结算场次记忆；重启服务不会自动恢复。停止后的场次摘要可在节目工具查看。测试不连接/向平台发言，也不自动开启OBS推流。

勾选语音后，启动会开启本机角色语音开关。浏览器权限、音频设备和语音服务仍影响是否可听见；请保持服务运行、页面打开、当前角色可见，避免系统休眠。持续文本和语音生成可能产生费用。24小时选项是运行上限，不代表已经完成24小时稳定性实测。
