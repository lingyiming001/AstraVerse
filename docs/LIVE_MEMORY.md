# 直播上下文与选择性记忆

角色直播设置中的“直播记忆与上下文”可选择近期上下文轮数，默认30轮，可选10、20、30、40、60轮。一轮包含一条观众输入或主持事件和一条角色回应；总正文预算为24000字，单条最多1200字，长内容会使实际可用轮数减少。此设置只用于公开直播，私聊仍使用自己的上下文配置。

“按兴趣形成直播记忆”默认开启。程序用角色性格、偏好、擅长和话题参考与已回应的公开弹幕做关键词近似匹配；明确要求“记住”的公开内容也可入选。它不保存每条弹幕，不从角色自己说的话、虚构故事或梦境生成事实记忆。明显的联系方式、密码、私密内容和指令注入不纳入长期记忆。这不是语义理解完备的人类记忆，兴趣判定仍可能遗漏。

记忆保存公开原句、来源事件与场次，不以昵称建立观众身份档案。每个角色最多保留120条，重复内容累计出现次数，召回时结合当前话题、重要性、出现次数与时间，从中选最多6条。观众说过只表示有过这种分享，不代表事实已核实，也不代表现在的观众就是之前的那个人。没有匹配内容时，角色不补造细节；不太感兴趣时仍可礼貌接话并给真实看法，不需要假装热爱所有话题。

直播页展开“直播记忆”可查看筛选结果并刷新。点击“清除直播记忆”需要确认，删除本角色长期记忆与场次记录，并清空本角色所有当前直播的近期上下文、虚构片段与节目接续笔记，作废清除前尚未发布的生成结果。仍在运行的场次会创建空白记录，之后新的观众交流可重新形成记忆。清除不会关闭之后的记忆形成；如需停止写入与召回，关闭上述开关。角色设置、私聊记忆、资料库和阅读进度不变。

关闭长期记忆后停止新增和召回，已有记录保留到手动清除；近期上下文仍用于连续接话。重启服务会丢失近期上下文并需重新开始直播，长期记忆保存在本机SQLite中。历史旧场次不会自动回填为新的兴趣记忆。

接口：`GET /api/live/agents/{id}/memory`查看记忆和设置；`DELETE /api/live/agents/{id}/memory`清除。旧的场次清除接口也执行同样的清除，避免旧档案重新成为记忆来源。
