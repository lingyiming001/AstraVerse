# 自然对话与记忆承接

本轮沿用已有角色记忆与长期摘要，不重置数据、不添加新的自动模型调用。

- 追问理解：遇到“那怎么练”“继续”等短句，检索查询加入最近两条用户消息；当前问题排在前面，避免历史话题覆盖新信息。实际发给对话模型的用户原文不变。
- 长期记忆：词项匹配先按相关程度排序，再按更新时间取有限条目；特定话题没有匹配时，不再用无关事实填满上下文。去除与已选记忆来源重复的历史原文；仍保留有限摘要背景。
- 表达：先回答当前具体意思，避免重新开场、固定三段式、每次结尾追问和情绪预设。记忆可能过时，以用户现在的更正为准；不得编造现实共同经历或离线活动。普通对话与直播共用这些表达原则。
- 页面：翻看历史时新消息不强制拉到底部；提供“回到最新消息”，自己发送消息后重新跟随。自动滚动仅作用于消息列表，避免推动整个页面。等待提示显示实际经过秒数，不伪装模型思考步骤或完成进度。
- 聊天区收紧重复入口，统一气泡、间距与输入焦点；可直达“记忆与资料”。移动端隐藏键盘快捷键文字，支持减少动画的系统偏好。

局限：检索仍为本地词项匹配，不是语义向量检索；没有确定性的偏好冲突消解或遗忘曲线。回复自然度需要真实模型和人工评测，提示词不能保证效果。等待提示不代表已实现流式输出或降低了模型推理耗时；本轮未改动语音合成链路。公开直播继续隔离私聊记忆。
