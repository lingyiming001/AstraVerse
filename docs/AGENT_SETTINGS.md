# 简化后的角色设置

入口：设置 → 角色设置，或舞台上的角色设置按钮。先选择要编辑的角色，各角色的内容独立保存。

基本设置默认只显示名字、一句话介绍、性格、说话方式四项。当前已有内容可以直接使用，不要求重新填写。模型、声音和记忆显示为摘要，可点击进入相应设置；背景、喜好、初次问候、擅长的话题与相处约定放在「更多人设细节」中，按需展开。

直播设置保留主题、面向的观众、话题参考和主持方式。主题和话题可留空。主持方式统一为「仅回应弹幕 / 无人聊天时自动接话 / 按作息主持」，代替分散的两个开关；原作息、时间和次数限制保留。节目提纲、直播口吻、内容边界、商业合作、排练均按需展开。本地连续试播仍在直播页选择时长后启动。

更多设置分为四个入口：

- 声音与表现：音色、语速、回答长度、主动性，表情和动作细节另行展开。
- 记忆与资料：记住聊天、长期记忆、手写记忆；资料库和记忆档案按需展开。
- 模型设置：默认跟随全局配置；需要独立供应商、密钥和能力路由时，再展开独立模型设置。
- 能力与自动行为：资源库和插件权限，以及自动选歌、动作、弹幕管理和灵感整理。

修改后点击底部「保存设置」，或「保存并试聊」保存成功后直接聊天。角色切换时保留本次打开页面中的草稿；关闭设置前仍需保存。名字和初次问候为空时会给出提示。

这次调整不迁移或重置已有角色数据，折叠的字段仍随整份角色配置保存。旧的记忆、声音、模型和直播快捷入口会进入对应的分类。自动直播已经统一公开杂谈，因此不再展示无实际效果的虚构内容轮换选项；旧字段继续保留以兼容原配置。

### 角色聊天依据

普通聊天和直播会结合当前角色身份、讨论擅长、偏好、获授权的资料与当前能力快照。资料标题表示知道该资料存在；只有提供了片段或阅读原文才可据此解释具体内容。人设擅长不授予工具权限。角色应保留自己的说话风格和观点，不必每轮介绍配置；缺少依据时说明不确定，并区分拟执行操作与实际完成。公开直播只包含公开资料，播放器未提供状态时视为未知。
