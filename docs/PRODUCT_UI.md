# 界面布局与列表规范

本轮统一现有产品的页面结构，保留全部主题与功能，不改用户的角色、模型、资源权限或直播配置。样式入口为`app/styles/productUI.css`，在旧样式之后加载，通过`product-ui`根类明确生效范围；颜色继续使用`shared/preferences/themes.ts`的主题变量。统一使用系统字体，移除原来的远程字体请求。

## 页面与导航

主导航分为工作台和资源管理，当前页面使用统一选中状态。宽屏显示完整侧栏，平板缩成图标导航，窄屏使用横向导航。页面标题、说明、主要操作保持相同层级。表单控件以36px为常用高度，主要字号13–14px，辅助内容11–12px；边框、圆角、间距和焦点状态统一。

角色、场景、音乐、书籍、图片、视频及歌词统一进入同一资源表格。原先同时展示的多组导入按钮收敛到页面右上方：分类页面直接导入该类，全部资源页通过菜单选择类型。

## 资源列表

- 采用原生table、caption、列标题，固定为名称、类型、来源、状态、操作五列。表头在表格滚动时保持可见；窄屏允许横向滚动，不挤压全部列。
- 搜索覆盖名称、描述和文件名，可与来源、类型和角色模型种类筛选叠加。支持默认顺序及名称自然排序，默认排序保留原数组顺序。
- 每页20/50/100项，筛选、排序、每页数量改变后回到第一页；删除后收敛到有效页。外部打开某个资源时，定位到该资源所在页。
- 每行保留一个主要操作与更多菜单。播放、暂停、使用角色、进入场景、阅读、图片预览和视频陪看继续使用原处理函数。
- 更多菜单收纳编辑信息/权限、替换源文件、删除。使用portal避免被表格滚动裁切；支持方向键、Home/End、Escape、Tab，以及窗口滚动/缩放时关闭。
- 编辑和删除采用原生dialog模态，背景不可操作；打开时聚焦字段或取消按钮，关闭后恢复原控件焦点。保存中禁用关闭，错误留在对话框内。
- 删除书籍明确提示后端全文与阅读位置也会删除；删除角色继续保留角色设置与聊天记录。原版权、作者、模型来源链接保留。

设置页、供应商列表、模型条目、能力路由和直播间列表沿用同一字体、控件与表面规范。角色配置上轮的基本/直播/更多三个入口保持。

## 已验证范围

前端结构与行为测试覆盖过滤/排序不修改原数组、3D/Live2D分离、20行分页初始状态、五列表头、版权及播放状态、空状态、菜单定位/键盘和对话框焦点调用。边界检查、TypeScript、Vite构建通过。

尚未完成浏览器截图验收：当前Work设置禁止本地浏览器，因此没有1440/1024/390宽度及六种主题的真实截图、像素检查或辅助技术验收。原生dialog的行为依赖浏览器实现，结构/事件单测不替代真实点击检查。此限制不应被表述为已经完成视觉验收。

### 批量导入

新增资源时文件选择器支持多选，按当前类别逐个导入并检查格式、单文件大小与持久化结果。批量结果对话框显示成功、失败及说明；个别文件失败不终止后续导入。替换已有资源保持单选并保留资源 ID。

### 音乐暂停

聊天中的明确音乐暂停请求（例如“先把音乐暂停一下”“音乐停一下”“别放歌了”）直接执行当前播放器暂停并核对 paused 状态，保留进度；无需等待文本模型。手动暂停会阻止本页面直播自动选曲恢复音乐，主动点击播放或重新点歌可恢复。较早返回的聊天音乐操作在手动调整后失效。

重复导入同类、同原始文件名的本地资源时，会在写入前要求选择“替换已有文件 / 跳过 / 两个都保留”，可勾选应用到本批次所有重复文件。替换沿用资源ID与设置；保留两份时文件名自动增加序号。同一批次内的重复也会检查。书籍替换后正文变化会重置进度。跳过单独统计，不算失败。
