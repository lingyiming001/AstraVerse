# v0.3 · 布局与角色自然表现

## 导航与设置

主导航只保留创作空间、虚拟角色、场景世界、音乐与舞蹈、资源库。MCP 与帮助中心全部收进设置，主页面不再展示这些技术/支持入口。导航打开资源对话框时，主页面标题与面包屑保持当前创作空间，避免误导成已切换到不存在的独立页面。

设置使用固定分组侧栏、独立滚动内容、固定内容标题和模型保存按钮。手机使用横向滚动分类，保留内容面积。

- 偏好设置：外观与体验、角色表现。
- 智能与模型：供应商、能力路由、多模态实验室。
- 连接与支持：MCP 与工具、帮助中心。

MCP 页面从后端实时发现工具，支持 JSON 参数编辑、Schema 展开、真实执行返回和连接说明。帮助页集中说明入门、快捷键、模型连接和资源限制。

## 主空间

扩大舞台/对话高度，统一边距、面板圆角、字体与对比度。标题显示当前角色；保存空间和沉浸模式放在标题右侧。舞台底部直接提供招呼、微笑、角色控制；角落保留镜头相关操作。

沉浸模式隐藏推荐世界与快捷内容，把高度留给舞台和聊天。外观、语音、沉浸和动态偏好保存在 `astraverse-preferences` 浏览器存储中；模型密钥仍只在后端。

浅色主题使用独立颜色覆盖，不再给整个页面做反色处理；3D 舞台、上传图像与媒体保持原色。

## 自然表现

增加眼白、虹膜、瞳孔和双层反光、鼻子、耳朵、颈部、拇指与手指轮廓，修正眉毛朝向。皮肤使用低强度物理材质；头发增加细微层次和滞后摆动。

眨眼在约 2.8–6.5 秒之间变化；指针活动后目光停留，空闲时轻微游移。呼吸叠加慢速变化，身体、肩臂和说话时头部有细微运动，所有动作保留关节手动控制。

模型语音可通过 Web Audio 采样实际播放信号的 RMS 能量，驱动口型开合；不使用每帧 React 状态更新。系统 TTS 无可访问波形时仍使用近似音节节律。这不是音素级 viseme，不能据此宣称真实唇语同步。

动态偏好支持系统/完整/减弱。减弱时减少自主律动、眨眼、舞台粒子与漂浮，用户明确触发的舞蹈/跳跃继续响应。

## 构建与交付

本轮按用户分工不运行功能测试、浏览器自动化或截图检查，只执行 TypeScript/Vite 构建与本地服务启动检查。实际交互、视觉效果与设备表现由用户验证。

新增 `npm start` 读取构建产物，在 127.0.0.1:5174 提供本机预览，并代理 REST/WS 到 127.0.0.1:8000。`deploy/start-local.sh` 提供重建与启动入口。它是本机构建版预览，不是公网生产部署。
