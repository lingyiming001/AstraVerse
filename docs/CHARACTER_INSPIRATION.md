# 角色灵感、兴趣与特殊知识

入口：角色设置 → 表达与表现 → 角色灵感与特殊知识。默认关闭，开启后先保存，且需开启聊天记忆与可用的角色文本模型。此功能不修改模型权重，而是把有来源的角色笔记保存到本地，并在相关对话中检索使用。

## 积累与整理

素材来自当前设定（背景、性格、偏好、习惯、能力）、角色资料的有限片段，以及后续成功模型聊天的用户原话/角色回复与本次实际提供的TXT/MD书籍片段。不扫描全部聊天历史、不读取整本书；每次最多4条资料前1800字、4本已提供的书籍片段。未提供正文的书名不是阅读经历。

来源记录先保留，整理模型再根据角色性格筛选有兴趣的内容，连接不同来源、压缩旧笔记或扩展成创意。输出只能是：

- interest：角色感兴趣的话题，不是观众身份事实。
- idea：角色个人理解与新联想，不冒充已经验证的知识。
- fiction：虚构故事种子，不作为书中原文或现实共同经历。

每条笔记最多40字标题、300字正文、8个可校验来源ID；公开/私密分别最多12条。整理使用同一角色的文本模型，但单独请求，不让它执行工具或改写核心设定。既有同范围笔记会作为下一次整理的输入，来源引用必须来自实际输入或既有来源；格式错误、无有效来源、超时或模型失败不会覆盖已有笔记。

第一次有素材即可整理，之后按配置间隔5–1440分钟（默认30分钟）重试/整理。服务内后台每60秒检查已保存角色，并采集新的设定/资料版本；普通成功模型聊天也触发收集。无新增素材不调用模型，未保存角色不会被后台轮询。每轮每个范围最多取12条待整理素材，公开与私密各最多一次调用，每次30秒超时；各角色整理的模型调用串行，避免同时堆积请求。聊天本身不等待整理。

这是运行服务内的任务，关闭应用服务后不会继续；素材与上次尝试时间持久保存，重新运行后继续检查，不补发错过时段的调用。模型调用有额外费用，不是无成本长期学习。

## 公开与私密隔离

公开设定及标记公开的资料可以形成公开灵感。用户互动、浏览器书籍片段和私密资料始终为私密来源；两个范围分开模型请求，不将私密原文输入公开整理任务。模型输出的可见范围不能自行扩大，由输入范围决定。

普通聊天可参考该角色的两类灵感；公开直播只使用公开灵感。公开来源也不代表内容真实或平台可播，创作标签、直播内容检查和虚构标识继续有效。当前没有“把私聊故事自动脱敏后公开”的能力；如需公开素材，应由运营者另外整理到公开资料中，而非自动泄露用户互动。

关闭聊天记忆或灵感功能后停止采集、自动整理与上下文使用，已有数据保留以便管理。消息明确表示不要记住/不保存或包含基础凭据关键词时跳过本轮采集；这只是保守词项检查，不能保证识别所有个人敏感内容。

## 存储与控制

数据保存在角色记忆SQLite数据库的独立表中，按角色ID隔离。来源使用哈希去重，最多200条；接近上限时，清理已处理且不被当前笔记引用的旧素材，保留可追溯来源。所有槽位仍被待处理或引用占用时暂停新增，待后续整理释放空间；不是无限档案。

界面可以立即整理、查看每条灵感的来源原文、清空全部灵感与来源。清空会递增代次并取消进行中任务，晚到的模型结果不能恢复已删内容；清空角色会话也清空派生灵感。未来的新对话、设定/资料后台采集仍可重新形成素材，若需持续停用，应同时关闭开关。

当前未实现单条笔记编辑/删除、长期故事章节管理、跨角色共享、向量检索或独立的事实审核。模型筛选可能遗漏有趣内容，输出也可能有错误；来源ID可追溯不等于语义已核验，需通过真实角色评测继续改进。
